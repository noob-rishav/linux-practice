# basic commands of linux
1. pwd (prints working directory)
2. ls (lists all the contents of the working directory)
3. cat (shows all the contents inside a file or a directory)
4. mkdir (makes a new directory)
5. cd (change directory)
6. head (shows some of the starting lines)
7. tail (shows some of the last lines)
8. touch (either creates a new file or update the time stamps if the file already exists)

# addition of new commands
1. ~ denotes the home directory
2. cd ../ (takes us one directory back)
3. .(represents the current working directory)
4. ls -a (shows all files including the hidden ones)
5. echo (like a print statement of the python)
6. man (this command is used to show up the manual of the different commands that we use)
7. help (this is similar to man command but this one is more conscise and is of more use)
8. nano (this command is used to edit files in the terminal)
9. ctrl+o (used to save the changes made)
10. ctrl+x (used to exit as using nano command , it takes control over the terminal)
11. more and less (this is also similar to head and tail but it shows along with the serial number and it also takes control over the terminal)
12. environment variable (they are made by using the upper case letters)
